# Clearline design system (from assets) — elevate wave

Technique: design-system-from-assets + specify-the-look.
Assets analyzed: `host-maya.jpg`, `cool-paper.jpg`, `clearline-hero.jpg`, live book card, Cal.com / SavvyCal bars.

## Fonts
- Display (host name only): Source Serif 4
- UI: IBM Plex Sans
- Meta/times: IBM Plex Mono (tabular)

## Colors
| Token | Hex | Use |
| --- | --- | --- |
| Field | `#f4f5f4` | cool paper field |
| Card | `#ffffff` | booker surface |
| Ink | `#121416` | text + black CTA |
| Vermillion | `#c41e3a` | selection ring / open-day dot |
| Open wash | `#d5dbe2` | open days (cool slate) |
| Stroke | `#d4d7db` | hairlines |

## Components
- Booker = one white card; host rail hairline; slots hero
- Week strip = primary day density (SavvyCal); Month = secondary
- Duration chips = 30 / 60 / 20 under meeting title
- Confirm = one screen, black CTA

## Do
- Flat fills, hairline borders, ≤3s job path
- Keep host photo visible (never opacity:0)

## Don't
- Courtyard linen/brass/sage, vibe-purple, glass, gradients-as-chrome
- Calendly-only stacked day lists as the hero metaphor
